# KRC - Mobile Tower Defense

KRC is an original, iPhone-first fantasy tower-defense game built with Phaser 3 and static files. It is inspired by classic lane defense structure without using copyrighted game assets.

## Play

Open `public/index.html` through a local web server or deploy the `public/` folder to GitHub Pages.

## Controls

- Tap a tower type, then tap a round build pad.
- Tap a built tower to upgrade or sell it.
- Tap `CALL` to start the next wave.
- Use `MET`, `ICE`, and `RLY` spells when enemies are near the gate.

## Current Features

- Portrait mobile layout tuned for iPhone-sized screens.
- One 10-wave level with escalating enemy mixes.
- Four tower families: Rangers, Runes, Mortar, and Guard.
- Barracks-style soldiers that block ground enemies.
- Upgrade, sell, wave-call, spell, reward, leak, victory, and defeat loops.
- Procedural graphics and Web Audio sound effects/music pulse.
