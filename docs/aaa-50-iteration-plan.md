# KRC AAA Competitor Program — 50 verified releases

Legal line: original KRC names, art, maps, audio, and code only. Kingdom Rush is a genre benchmark, never a copy target. Do not claim indistinguishability.

Baseline after v1.0.8: playable 3-map campaign, 4 tower roles, hero, spells, Kenney+synth audio. Presentation is still prototype-grade (Arial, flat HUD rects, card list campaign, blob shop icons).

Each item is one numbered patch release after independent syntax/tests/`git diff --check`/live desktop+portrait gates. Publish only verified slices.
