# KRC Wow / AAA gaps (harsh judge, 2026-08-21)

Live: v1.1.9 Forest Gate. Not AAA. Campaign hover 1.1.6–1.1.9 is a dead end.

Legal: original KRC only. Kingdom Rush is a bar, never a copy.

## Verdict
Indie/AA vertical slice. Campaign board looks authored. Battlefield still looks like a decorated systems demo. Agent output that adds mortar-line speckles on 96px stamps is not Wow.

## Ranked gaps (Wow first)

1. Forest Gate as a PLACE
   Gate is a muddy 96px stamp + orange glow circles. Path is a tan ribbon. Trees are random stamps. MARCH screen must show a unique gate, rutted road, and one landmark. If a still frame is not a postcard, FAIL.

2. Combat animation density
   Walk sheets exist. Fight still reads as stickers. Need fire/recoil per tower family, hit stagger, posed deaths that linger, debris. reducedMotion stays frame 0.

3. Tower/hero as characters
   Rangers/Runes/Mortar/Guard at phone distance must change silhouette on upgrade. Captain needs idle/attack/ability that is not a bob. Guards 24px+ with readable spears, no overlap mush.

4. Spell and projectile authorship
   Meteor/Frost/Rally must have distinct bursts. Arrows/runes/bombs need trails that read in a crowd.

5. Persistent world after combat
   Corpses, scorch, craters, spent arrows. The lane after wave 3 should not look like wave 0.

6. Audio mix that reacts
   Location ambience, wave-danger music, distinguishable tower shots, priority mix so the field is not a beep wall.

7. Teaching in the first 60 seconds
   Why this tower, why CALL early, why the bend matters — without a wiki. MARCH modal is a start, not a tutorial.

8. Desktop chrome
   420×760 island in a dark well. Use the wasted frame or own the portrait and stop pretending it is a PC AAA window.

9. Content breadth (after the slice looks expensive)
   Second hero, more maps with unique topology, Iron/challenge. Do not add maps while Forest Gate still looks like ellipses.

10. Cohesion
    Outline weight, scale, palette, lighting. Critic cannot call it a sticker sheet.
